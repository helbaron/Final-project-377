# Future Saver

## Project Description

Future Saver is a personal finance dashboard designed to help young adults manage their finances in one centralized system. The application allows users to create savings goals, track debt, monitor investments, and view stock market data through a modern financial dashboard.

The purpose of the project is to help young adults develop stronger financial habits early in life by providing a simple and interactive platform for tracking financial progress.

Features include:

- Multi-step onboarding flow
- Savings goal tracking
- Debt payoff tracker
- Investment monitoring
- Net worth dashboard
- Stock market section
- AI-style financial insights
- Responsive dashboard interface
- User-specific financial profiles using Supabase

---

## Target Browsers

The application was designed and tested primarily for modern desktop browsers.

Supported browsers include:

- Google Chrome
- Safari
- Microsoft Edge
- Mozilla Firefox

The application is also compatible with mobile browsers on:

- iOS Safari
- Android Chrome
